## 三、部署步骤

### 步骤 1️⃣ 创建私有 GitHub 仓库（网页操作，约 2 分钟）

1. 浏览器打开 [github.com](https://github.com) 并登录
2. 点右上角 **「+」→ New repository**
3. 填写：
   - **Repository name**：建议 `learning-mentor-intel`（可自定，勿用中文）
   - **Private** ← 务必选中（默认即可，无需加 README/.gitignore/license，本地已有文件）
4. 点绿色 **Create repository**
5. 记下页面显示的仓库地址，形如 `https://github.com/<你的用户名>/learning-mentor-intel.git`

### 步骤 2️⃣ 本地初始化并推送代码（终端命令，约 3 分钟）

打开终端（git-bash），执行：

```bash
cd "/d/乔一禾/项目工作区/多Agent学习导师"

# 1) 初始化仓库
git init
git branch -M main

# 2) 暂存全部文件（.env/.hermes/缓存等已被 .gitignore 排除）
git add .
git status        # 检查：确认没有 .env、.hermes/、data/progress/ 等被列入

# 3) 提交
git commit -m "feat: 每日情报采集与飞书推送（REQ-20260813-001 T4）"

# 4) 关联远程仓库（换成你自己的用户名/仓库名）
git remote add origin https://github.com/<你的用户名>/learning-mentor-intel.git

# 5) 推送（首次会要求认证，见下方说明）
git push -u origin main
```

**推送认证说明**（`gh` CLI 不可用，二选一）：

- **方式 A — Personal Access Token（PAT）**：
  GitHub 网页 → 右上角头像 → **Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)** → 勾选 **`repo`** 权限 → Generate → **立即复制**（只显示一次）。推送时用户名填你的 GitHub 用户名，密码粘贴 PAT。
- **方式 B — Git Credential Manager**：Windows 安装 [Git Credential Manager](https://github.com/git-ecosystem/git-credential-manager) 后，推送时自动弹出浏览器登录，一次配置长期免密。

推送完成后，到仓库网页确认文件列表包含：`.github/workflows/daily-intel.yml`、`scripts/`、`requirements.txt`、`.env.example`。

## 四、常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 推送步骤显示**橙色**勾但飞书没收到 | 设计如此：`push_intel.py` 步骤设了 `continue-on-error: true`（网络偶发失败不红牌），需看该步日志确认失败原因 | 点进该步骤展开日志，按报错处理（多为临时网络问题，下次定时自动恢复） |
| 飞书提示凭证错误 / `code 10303` | 三个 Secret 名称不精确（大小写/拼写）或值复制不完整 | Settings → Secrets 核对 3 个名称与值；重新保存后再次手动触发 |
| 定时任务没准点跑 | GitHub 免费仓库 schedule 有延迟（可能迟到几分钟~十几分钟），属正常 | 耐心等或手动触发兜底 |
| 采集步骤日志显示某个数据源失败 | `intel_collector.py` 优雅降级设计，4/5 源可用即可，日志有标注 | 正常现象，不影响推送 |
| 推送消息里个别条目是旧闻 | 部分 RSS 源会回灌历史条目，KM-001 已建议后续在采集端过滤 2 年以上旧闻（backlog #2） | 可接受；后续迭代优化 |
| 推送失败想立即重试 | — | Actions → 该次运行 → 右上角 **Re-run all jobs** |

## 五、云端架构速览

```
GitHub Actions (ubuntu-latest)  每天 07:00/12:00/19:00 北京时间
├─ checkout 代码
├─ pip install requests feedparser
├─ python scripts/intel_collector.py --min-score 2
│     └─ 云端现场生成 data/daily-intel/intel-YYYY-MM-DD.{json,md}
└─ python scripts/push_intel.py   （continue-on-error: true）
      ├─ 读环境变量 FEISHU_APP_ID / FEISHU_APP_SECRET / FEISHU_CHAT_ID（来自 Secrets）
      └─ 组装「距考天数+关键动态+与我相关+建议动作」→ 飞书 interactive 卡片
```

健壮性设计：无当日情报 → 跳过推送（exit 0）；密钥缺失 → 报错（exit 1）；网络失败 → 自动重试 1 次（exit 2 且不红牌）。
