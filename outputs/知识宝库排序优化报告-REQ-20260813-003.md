## 一、需求概述

用户反馈知识宝库新旧文件混杂，要求：

> 「知识宝库里的资料和文件有的是老文件，这种文件肯定先看最新的可以把历史有关文件给出链接方便查看应先了解当下国情和文件还有最新的文件后边再补充历史文件」

核心诉求：**最新文件优先展示 → 历史相关文件给链接/折叠 → 先看最新、后补历史**。

原缺陷：
- 后端 `server/api/knowledge.py` 第29行 `sorted(kb_dir.rglob("*.md"))` 按文件名字母序排列，新旧混杂（如「2024-2025年重要中央会议」与「2026年政府工作报告」混排）；
- 前端 `renderKnowledge()` 按 API 返回顺序渲染，无时间排序、无「最新」标识、无历史分组。

## 二、改动清单

### 2.1 后端 `server/api/knowledge.py`（`_list_cards()`）

| 改动点 | 说明 |
|---|---|
| 排序逻辑 | 原文件名字母序 → 按文件 mtime **倒序**（最新在前）：`sorted(kb_dir.rglob("*.md"), key=lambda p: p.stat().st_mtime, reverse=True)` |
| 新增字段 | 每张卡返回 `update_time`（格式化 `YYYY-MM-DD HH:MM`，取文件 mtime 本地时间） |
| 保留字段 | `module`（模块信息）保留，供前端分组/展示 |

### 2.2 前端 `static/platform.html`（`renderCardList()` 重构 + CSS）

| 改动点 | 说明 |
|---|---|
| 时间排序 | 列表按 `update_time` 倒序渲染（最新日期在前） |
| 最新优先区 | 顶部「🆕 最近更新 · YYYY-MM-DD」区，最新日期（2026-08-13）的 4 张卡平铺展示，带朱砂色「🆕 最新」徽标 |
| 历史折叠组 | 下方「📜 历史资料（N）」虚线边框折叠组，**默认收起**，点击表头展开/收起，展开后历史卡与最新卡同等可点击打开详情 |
| 更新时间展示 | 每张卡 module 行显示「📅 YYYY-MM-DD 更新」（`update_time` 字段） |
| 搜索兼容 | 搜索时全部平铺过滤结果，折叠组内历史卡可被搜出（不丢结果） |
| 水墨风格 | 新增 `.kb-date-label` / `.kb-history` / `.kb-history-head` 等样式，沿用现有 `--vermillion` / `--border` / `--ink-light` 水墨 CSS 变量体系，虚线边框 + 衬线字体，与整体风格协调 |
