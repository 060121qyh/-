# 多Agent协作协议 — 文件坐标通讯

> PM-001 不需要"调用"其他 Agent。它只需往 `inbox/` 放任务单。
> 我（编排器）检测到新文件后自动拉起对应 Agent。

## 目录结构

```
coordination/
├── inbox/          ← PM-001 往这里丢 *.json 任务单
├── outbox/         ← TA/QA/KM 往这里丢 *.md/*.json 产出
└── decisions/      ← PM-001 读 outbox 后写下一步决策
```

## PM-001 如何指挥团队

### 步骤1：写任务单
PM-001 按 `task-template.json` 格式写一份任务单，放入 `inbox/`：
```
coordination/inbox/pm-to-ta-T004.json
coordination/inbox/pm-to-qa-review.json
coordination/inbox/pm-to-km-audit.json
```

### 步骤2：编排器自动调度
我检测到 `inbox/` 有新文件 → 读取内容 → 拉起对应的 Agent (delegate_task) → Agent 工作。

### 步骤3：Agent 交付产出
Agent 完成后将结果写入 `outbox/`：
```
coordination/outbox/ta-T004-完成报告.md
coordination/outbox/qa-审查结果.md
```

### 步骤4：PM-001 读结果做决策
我在下一轮对话把 `outbox/` 内容递给 PM-001 → PM-001 决定下一步 → 写新的任务单或标记完成。

## Agent 通讯格式

| 发件人 | 收件人 | 文件命名 | 放入目录 |
|--------|--------|----------|----------|
| PM-001 | TA-001 | `pm-to-ta-{任务ID}.json` | `inbox/` |
| PM-001 | QA-001 | `pm-to-qa-{任务ID}.json` | `inbox/` |
| PM-001 | KM-001 | `pm-to-km-{任务ID}.json` | `inbox/` |
| TA-001 | QA-001 | `ta-to-qa-{任务ID}.md` | `outbox/` |
| QA-001 | PM-001 | `qa-report-{任务ID}.md` | `outbox/` |
| KM-001 | PM-001 | `km-review-{任务ID}.md` | `outbox/` |

## 当前状态追踪

PM-001 在 `decisions/状态看板.md` 维护全局进度，每次决策后更新。
