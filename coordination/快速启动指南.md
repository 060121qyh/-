# 多Agent对话 — 快速启动指南

## 你需要做的事（1分钟）

在 Hermes 左侧对话栏点 **+** 新建四个对话，分别命名：

| 对话名称 | 对应 Agent | 第一句话（复制粘贴） |
|----------|-----------|---------------------|
| `PM-001 赛博产品经理` | 产品经理 | `@启动 PM-001` |
| `TA-001 赛博工程师` | 技术执行 | `@启动 TA-001` |
| `QA-001 赛博质检官` | 审查验收 | `@启动 QA-001` |
| `KM-001 赛博学监` | 知识管理 | `@启动 KM-001` |

> 四个对话标签页会出现在左边栏，每个独立上下文、独立环境、互不污染。

## 工作流

```
PM-001 对话                 TA-001 对话              QA-001 对话              KM-001 对话
   │                           │                        │                        │
   │ 读状态→写inbox任务单       │                        │                        │
   │  ↓                        │ 扫inbox→发现任务       │                        │
   │                           │  ↓                     │                        │
   │                           │ 写代码→curl验证        │                        │
   │                           │  ↓                     │                        │
   │                           │ 写outbox/完成报告      │                        │
   │                           │                        │ 扫inbox→发现审查任务   │
   │                           │                        │  ↓                     │
   │                           │                        │ curl测试→代码审查      │
   │                           │                        │  ↓                     │
   │                           │                        │ 写outbox/验收报告      │
   │ 读outbox→看交付物         │                        │                        │      │ 扫outbox→审核知识卡    │
   │  ↓                        │                        │                        │      │  ↓                     │
   │ 更新状态看板→下轮任务     │                        │                        │      │ 写outbox/审核报告      │
```

每个 Agent 只在自己的对话标签页里工作，通过 `coordination/inbox/` 和 `coordination/outbox/` 交换信息。

## 通信目录

```
coordination/
├── inbox/           ← PM-001 投递任务单（JSON）
├── outbox/          ← TA/QA/KM 投递交付物（MD）
├── decisions/       ← PM-001 维护状态看板
├── 协作协议.md       ← 所有Agent必读的通讯规则
├── task-template.json ← 任务单格式模板
└── 启动提示词-*.md   ← 四个Agent的启动身份卡
```
